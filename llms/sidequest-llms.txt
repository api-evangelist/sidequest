# SideQuest

> SideQuest is a VR content-discovery platform and third-party app store for Meta Quest, PCVR, Pico, Magic Leap and WebXR — home to sideload-only, early-access and indie VR apps and games. SideQuest operates a Public REST API for browsing app listings and reading user profiles and achievements.

## API

- Name: SideQuest API (Public API), OpenAPI 3.0.0, version 0.2.0
- Auth: HTTP Bearer (OAuth 2.0 access token). Device-style short-code login: POST /v2/oauth/getshortcode then poll POST /v2/oauth/checkshortcode; refresh via POST /v2/oauth/token (grant_type=refresh_token).
- Public reads (no token): GET /v2/apps, GET /v2/users/{id}/view-profile, GET /v2/developers
- Scoped reads (bearer token): GET /v2/users/{id} (user.basic_profile.read), GET /v2/users/{id}/apps/{apps_id}/achievements (user.app_achievements.read)
- Pagination: offset (skip, limit); sorting via sortOn + descending
- Errors: plain-text (text/plain) messages with HTTP 400/403/404 (not RFC 9457)

## Key operations

- GET /v2/apps — list/search VR apps with filters (app_categories, app_platform, app_comfort_level, supports_quest/pico/magic_leap/link, is_webxr, early_access, staff_picks, search/full_search, updated_since/created_since)
- GET /v2/users/{route_users_id} — get a user profile (scoped)
- GET /v2/users/{route_users_id}/view-profile — view a user's public profile
- GET /v2/users/{route_users_id}/apps/{apps_id}/achievements — list a user's unlocked achievements for an app
- GET /v2/developers — list developers
- POST /v2/oauth/token, /v2/oauth/getshortcode, /v2/oauth/checkshortcode — OAuth login/refresh
